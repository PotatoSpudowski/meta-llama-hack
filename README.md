# Meta Llama Hack

This repository provides tools and scripts for the Meta Llama Hack project.

## Overview

This project is an experimental research project aimed at integrating Meta Llama model hacks into modern pipelines.
It leverages various scripts and design assets to facilitate ease of integration and testing.

## Repository Structure

- **/fonts**: Contains font files used across the project.
- **/uploads**: Storage for image assets.
- **/static**: Static resources for front-end use.
- **Python Scripts**: Including test scripts (`test.py`, `test2.py`), and `sarvam.py` for utility purposes.
- **index.css**: Stylesheet for project front-end.

## Setup

1. Clone the repository:
   ```bash
   git clone <repository_url>
   ```

2. Change to the repository directory:
   ```bash
   cd meta-llama-hack
   ```

3. (Optional) Checkout the feature branch for readme updates:
   ```bash
   git checkout feature/add-readme
   ```

4. Install necessary dependencies as outlined in each script comments.

## Usage

- Run test scripts:
   ```bash
   python test.py
   python test2.py
   ```

- Explore individual scripts like `sarvam.py` for additional functionalities.
